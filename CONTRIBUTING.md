# Katkıda Bulunma Rehberi

Bu depo disiplinlerarası bir araştırma arşividir. Katkılar akademik dürüstlük ve kaynak gösterme ilkesine dayanmalıdır.

## Nasıl Katkı Sağlanır?

1. **Fork** edin ve bir dal (`feature/konu-adi`) oluşturun.
2. İlgili modül klasörüne içerik ekleyin veya `data/` altındaki yapılandırılmış dosyaları güncelleyin.
3. Her iddia için mümkün olduğunca birincil veya ikincil akademik kaynak belirtin.
4. Pull request açın; özet kısmında hangi modülü ve hangi soruyu ele aldığınızı yazın.

## İçerik Standartları

| Kriter | Beklenti |
|--------|----------|
| Dil | Türkçe (özgün alıntılar orijinal dilde kalabilir) |
| Ton | Akademik, tarafsız; spekülasyonlar açıkça etiketlenmeli |
| Kaynak | Kitap, makale, müze envanteri veya EDCS/ETCSL gibi dijital korpus |
| Biçim | Markdown; tablolar ve başlık hiyerarşisi tutarlı olsun |

## Modül Yönlendirmesi

- **Arkeoloji:** Kazı raporları, koordinatlar, katman kronolojisi → `arkeoloji/`
- **Metin analizi:** Paralel motifler, çeviri alıntıları → `metin-analizi/`
- **Etimoloji:** Köken açıklamaları, dil ailesi notları → `etimoloji/`
- **Hukuk / toplum:** Kanun maddesi karşılaştırmaları → `sosyoloji-hukuk/`
- **Yapılandırılmış veri:** JSON şemalarına uygun güncellemeler → `data/`

## Tartışma Konuları

Açık araştırma soruları için GitHub Issues kullanın. Şablon: `.github/ISSUE_TEMPLATE/arastirma-sorusu.md`

## Reddedilecek Katkılar

- Kaynaksız iddialar veya propaganda tonu
- Telif hakkı ihlali (tam metin kopyaları yerine alıntı + referans)
- Kişisel saldırı veya mezhepsel polemik

Teşekkürler — geçmişin tablet arşivini birlikte genişletelim.
